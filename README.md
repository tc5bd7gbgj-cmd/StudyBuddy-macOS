# StudyBuddy for macOS

This repository contains a native macOS SwiftUI app inspired by the original Python StudyBuddy app. It is designed to be opened directly in Xcode and built as a macOS app.

## What is included

- Flashcards with Leitner-style review boxes and due dates
- Study tracker with daily minutes and session logging
- Past paper tracking and weak-topic notes
- Notes and import support for text files and images
- Calendar for homework and milestones
- Essay planner and essay notebook
- Simple insights and mini-games

## Open it in Xcode

1. Open the repository in Xcode.
2. Choose the `StudyBuddyApp` executable target.
3. Select a macOS destination.
4. Press Run.

## Local data location

The app stores user data in:

`~/Library/Application Support/StudyBuddyApp/`

## Notes

This is a native SwiftUI macOS port of the original Python concept, reworked for the Apple ecosystem. It keeps the same core study workflow and data model, while adapting the interface to a desktop app experience.
